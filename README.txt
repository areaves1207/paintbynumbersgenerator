Hi!
This Paint By Numbers Generator (PBN Gen) is my first full stack project!
Check it out at https://pbn-gen.vercel.app/

I was inspired to work on this project after seeing ads for paint by number canvases online, 
and wanted to see if I could proceduarlly generate my own, since one of my favorite classes during my master's studies was a computer vision course.
The project, in the end, took longer than expected, but I have learned so much about full stack development.

Over the course of a few months, I have worked on implementing almost everything
from the backend myself. I have written my own K-Means Clustering algorithm,
Canny edge detector, palette generator, etc.

It's been a super fun project to work on.

Thanks for checking this out!
